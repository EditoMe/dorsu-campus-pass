# DOrSU Digital Campus Pass

ITMSD 1 — Laboratory Exercise 03: React Native Fundamentals
Fundamentals of Mobile Design and Tools — DOrSU FACET

## Overview

A mobile app prototype built with Expo, React Native, and TypeScript that
simulates a student's digital campus ID pass, including a live gate-scan
counter and an active/suspended status toggle.

## Tech Stack

- Expo SDK 57
- React 19
- TypeScript
